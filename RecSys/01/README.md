# 🎧 RecSys ДЗ 1: Collaborative filtering рекомендации музыки (Botify)

*Учебная задача курса "Машинное обучение на больших объемах данных", ФПМИ МФТИ, 2026*

---

## 📋 Условие задачи

Музыкальный сервис Botify готовит рекомендации треков для пользователей. Сервис растет и развивается, а вот рекомендательная система в его основе пока далека от совершенства. В качестве **бейзлайна** используется collaborative filtering подход — модель обучена с использованием библиотеки LightFM.

**Цель:** обучить модель, которая побьёт **текущий бейзлайн** по метрике **NDCG**.

### Критерий успеха
Ваша модель лучше, чем бейзлайн по метрике NDCG.

---

## 📦 Исходные данные

**Датасет:** взаимодействия пользователей Botify

Формат строк:
```
user,track,time
0dffdaaffb460ead08234a09f625d3e8,4252,0.26
a5a049b5d915c48ee66fcf482818b30b,326,1.0
```


- Сабмиты — неограниченно; до конца чемпионата открыт лидерборд по **public** части
- Финальная оценка — по **private** части, результаты сразу после окончания

### Нужно отправить
1. Сабмит (сколько угодно)
2. Текстовое описание решения (одно)

### Можно
1. Любые изученные алгоритмы, предпочтительно — Collaborative filtering
2. Улучшать алгоритмы

### Нельзя
1. Пользоваться данными из модуля `sim`
2. Дособирать данные

## 🧮 Оценка

- **[Макс: 25]** ДЗ №1: `5 + (s - b) * (20 / (m - b))`, где
  - `s` — NDCG вашего решения
  - `m` — NDCG первого места в лидерборде
  - `b` — NDCG бейзлайна
