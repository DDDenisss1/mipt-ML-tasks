## ℹ️ О репозитории

Этот репозиторий содержит **решения домашних заданий** по машинному обучению на больших данных в рамках курса ФПМИ МФТИ.

Здесь представлены:
- ✅ **RecSys**: рекомендательная система музыкального сервиса Botify (Collaborative Filtering, EASE, Item–Item KNN, implicit ALS)
- ✅ **GNN (Graph Neural Networks)**: задачи на графовых нейросетях (*в процессе*)
- ✅ **LLM (Large Language Models)**: работа с большими языковыми моделями (*в процессе*)

Каждое решение включает:
- Исходный код (Python скрипты/ноутбуки)
- Подробную документацию с разбором архитектуры моделей
- Описание эксперимента, подбора параметров и итоговых метрик
- Сэмплы данных для воспроизводимости
